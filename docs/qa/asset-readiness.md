# 背景画像差し替え準備 QA — 2026-10-17

基点コミット: `f59cc1f`。既存コミット・Asset名・Assetの画像ファイルは変更していない。

## 変更内容

- 地層画像は縦横比を保つAspect Fillとセクション単位のクリップで描画する。
- セクション高は画像の解像度から独立した1000pt。画面幅や画像のscale指定を変えても世界座標は変わらない。
- 隣接する上下端を同じ式でピクセル境界へ丸め、スクロール中のサブピクセルの隙間を防ぐ。
- コード描画のフォールバックもセクション内でクリップし、隣の画像へはみ出さない。
- ホーム画像を画面サイズ内に収めてクリップする。
