# 問題作成フォーマット（Gemini 用）

ドパリカの問題は **2択** です。Gemini に下のフォーマットで書かせて `.txt` にまとめ、取り込みスクリプトで追加します。問題IDは取り込み時に自動で振られます（書かないでください）。

## 1問のフォーマット

```
分野: 地学
学年: 中1
問題: 流れる水が土地や岩石をけずるはたらきを何といいますか。
正解: 侵食
不正解: 堆積
解説: 流れる水が地面をけずるはたらきを侵食、土砂を積もらせるはたらきを堆積といいます。
---
```

- 1問ごとに `---` の行で区切る（空行だけでも区切れます）。
- `#` で始まる行はコメント（無視されます）。
- 項目名は全角コロン `：` でも半角 `:` でも可。
- **選択肢の並び（A/B）は書かない**。取り込み時に正解がA・Bに散らばるよう自動で決まります。

| 項目 | 必須 | 内容 |
|---|---|---|
| 分野 | ○ | `生物` `化学` `物理` `地学` のどれか |
| 学年 | 任意 | `中1` `中2` `中3`（省略時は中1） |
| 難易度 | 任意 | `1`〜`3`（省略時は1） |
| 問題 | ○ | 90字以内（目安は50字以内） |
| 正解 | ○ | 24字以内 |
| 不正解 | ○ | 24字以内。**1つだけ**書く |
| 解説 | ○ | 140字以内（目安は1〜2文） |
| 単元 | 任意 | 参考用（取り込みでは使いません） |

○×問題にしたいとき: `正解: ○` `不正解: ×`（または `正解: ×` `不正解: ○`）。この場合は並びが固定で、○がA・×がBになります。

## 作問のルール

- 中学理科の範囲。**4分野（生物・化学・物理・地学）をまんべんなく**。
- 1問につき知識は1つだけ。画像・図・表を見ないと解けない問題は作らない。
- 不正解は「もっともらしいが、はっきり間違い」のもの。正解と紛らわしい別の用語・近い数値・逆の性質が良い。
- 「〜でないものはどれか」「正しくないものを選べ」のような否定の問題は避ける。
- 同じ問題・ほぼ同じ言い換えを作らない（同じ問題文は取り込み時に自動でスキップされます）。
- 答えが複数ありうる問題、教科書で表現が割れる問題は避ける。
- 数値問題は単位まで正解に書く（例: `340 m/s`）。
- 解説は「なぜそうなるか」を1〜2文で。正解の言い換えだけにしない。

## Gemini に渡す指示文

> あなたは日本の中学理科の問題作成者です。次のフォーマットで、2択クイズを {N} 問作ってください。出力はフォーマットのテキストだけにしてください（前置き・番号・コードブロックは不要）。
>
> フォーマット（1問ごとに `---` で区切る）:
> ```
> 分野: （生物/化学/物理/地学のどれか）
> 学年: （中1/中2/中3）
> 問題: （50字以内の一問一答。画像不要）
> 正解: （24字以内）
> 不正解: （24字以内。もっともらしいが明確に誤りの選択肢を1つだけ）
> 解説: （なぜそうなるかを1〜2文）
> ---
> ```
> 条件:
> - 単元は「{単元名}」。（複数なら均等に）
> - 4択ではなく必ず2択（正解1つ、不正解1つ）。
> - 「〜でないものはどれか」のような否定形の問題は作らない。
> - 同じ知識を問う問題を重複させない。
> - 正解の位置は書かない。

`{N}` は 30〜50 問くらいずつがおすすめです（多いと品質が下がります）。`{単元名}` を変えて何回かに分けて作ると、偏りが出にくくなります。

## 取り込み

1. 作った `.txt` をまとめて置く（例: `~/Downloads/questions_01.txt`）。
2. まず確認だけ（何も書き込みません。エラーは行番号つきで出ます）:

```bash
python3 tools/import_questions_txt.py ~/Downloads/questions_01.txt --dry-run
```

3. 問題なければ取り込み:

```bash
python3 tools/import_questions_txt.py ~/Downloads/questions_01.txt
```

- 既存の問題とID・内容は一切変わりません。新しい問題が最後のIDの次から追加されます。
- エラーが1件でもあると、何も書き込まずに止まります。直して再実行してください。
- ファイルを複数並べて一度に取り込むこともできます。


## 図・表・グラフつきの問題（`図表:`）

問題に **表・グラフ・図** をつけられます。アプリの中で描かれるので、画像ファイルは要りません。`図表:` の行に **1行のJSON** を書きます（`問題:` の次あたり）。

```
分野: 物理
学年: 中1
問題: 表から考えて、水深50mの水圧は何気圧ですか。
図表: {"kind":"table","headers":["水深(m)","水圧(気圧)"],"rows":[["0","1"],["10","2"],["20","3"],["30","4"],["40","5"]],"caption":"水深と水圧（水面は1気圧）"}
正解: 6気圧
不正解: 5気圧
解説: 水深が10m深くなるごとに、水圧は約1気圧ずつ増えます。
---
```

| 種類 | JSON | きまり |
|---|---|---|
| 表 | `{"kind":"table","headers":[...],"rows":[[...]],"caption":"..."}` | 列は5つまで。各行の列数は `headers` と同じ |
| 折れ線グラフ | `{"kind":"chart","chartType":"line","xs":[..],"ys":[..],"xLabel":"水深(m)","yLabel":"水温(℃)","caption":"..."}` | `xs` と `ys` は同じ数（2点以上） |
| 棒グラフ（横向き） | `{"kind":"chart","chartType":"bar","categories":[..],"values":[..],"yLabel":"割合(%)","caption":"..."}` | `categories` と `values` は同じ数 |
| 図 | `{"kind":"diagram","name":"trench","caption":"..."}` | `name` は下の5つ。部分には A・B・C… の記号がついている |

用意してある図（`name`）:

- `ocean_zones`: 海の深さの区分。A=0〜200m、B=200〜1000m、C=1000m〜
- `trench`: 海溝の断面。A=海溝、B=沈みこむプレート、C=火山
- `ridge`: 海嶺の断面。A=海嶺、B=上昇するマグマ、C=遠ざかるプレート
- `food_chain`: 食物連鎖 A→B→C→D（食べられる側から食べる側へ）
- `water_pressure`: 水そう。A・B・Cの順に深く、矢印が長いほど水圧が大きい

注意:
- 図の記号（A・B・C）は、問題文で「図のAは…」のように参照します。
- 取り込み時に形が合っているかを調べ、合わなければエラーで止まります（何も書き込みません）。
- 新しい種類の図が必要なときは、アプリ側（`FigureView.swift`）に描画を足す必要があります。
